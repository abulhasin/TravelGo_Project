# 🌍 TravelGo – Explore the World

TravelGo is a simple and responsive travel website designed to help users discover beautiful destinations, explore travel experiences, and get useful travel information. The project provides an attractive interface with interactive elements and basic user authentication form validation.

## ✨ Features

- **Home Page:** Attractive landing page with an interactive image carousel.
- **Navigation Bar:** Easy navigation between different pages.
- **Login Page:** Login form with basic credential validation.
- **Sign Up:** Registration form with password confirmation.
- **About Page:** Information about the TravelGo platform.
- **Contact Form:** Contact form with basic JavaScript validation.
- **Responsive Design:** Built using Bootstrap 5 for different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3

## 📁 Project Structure

- `index.html` – Homepage
- `login.html` – Login and registration page
- `about.html` – About and contact page
- `style.css` – Custom styling
- `script.js` – JavaScript functionality
- `images/` – Project images

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Make sure all files and images are in their correct folders.
4. Open `index.html` in your browser.

## 🎯 Project Purpose

This project was developed as a practical web development project to improve my understanding of HTML, CSS, JavaScript, Bootstrap, webpage structure, and basic form validation.
